# MindNest

Otak kedua Chek Chop, ditemani maskot **Nesty**: lepaskan fikiran, lihat peta, buat satu langkah.

Warna jenama: ungu #5B1BC4 (gradien logo #9A3CF2 → #3C07A1), latar lavender #F5F0FD, madu #E8C266 untuk perkara baru. Mod Malam kekal gelap hangat (amber), tanpa ungu terang.

- **Lepaskan**: cakap atau taip, jawab "Bila?", siap.
- **Peta**: 6 cabang hidup (MSM, Kopi Lata, Staf, Marketing, Sistem, Peribadi). Ketik satu, yang lain senyap.
- **Sekarang**: satu perkara sahaja. Siap, Esok, atau Pecahkan kecil.
- **Mod Malam** (selepas 9 malam): apa perlu esok + rasa hari ni.

Repo ini hanya kod paparan (PWA, GitHub Pages). Data disimpan dalam Google Sheet peribadi melalui Apps Script API yang memerlukan kunci. Kunci tidak disimpan dalam repo ini.
